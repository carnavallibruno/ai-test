# My Skill

Explain why the decisions you made were made and how that impacted the performance and complexity of the project.

## When to Use

- Use this skill when creating a plan to implement in the project

## Instructions

- Explain why you made all of your decisions within a plan one by one
- Be clear about your decision-making, show why you decided to to one way instead of another, and why some things you might have chosen to emphasize leveraging performance instead of simplifying code by using a lib
